# Fitzo Landing Page

> **Train Smarter, Build Faster** — Science-based fitness tracking for serious lifters

A Next.js 14 website for Fitzo, with a liquid chrome theme, a five-screen showcase captured from the real app, and product content aligned with the app's October 2026 releases. See [DESIGN.md](./DESIGN.md) for the design system, source notes and UI verification commands.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## ✨ Features

- 🎨 Liquid chrome surfaces over graphite
- 🎭 Smooth Framer Motion animations
- 📱 Fully responsive mobile-first layout
- ♿ Keyboard navigation, visible focus, reduced-motion support and responsive checks
- ⚡ Static pages and a local interactive product preview
- 🔍 Complete SEO optimization
- 📄 Privacy Policy & Terms of Service pages
- 🎯 Custom 404 page

## 🛠️ Tech Stack

- **Framework:** Next.js 14.2.35 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 3.4.1
- **Animations:** Framer Motion 12.34.1
- **Icons:** Lucide React 0.574.0
- **Fonts:** Archivo & Martian Mono
